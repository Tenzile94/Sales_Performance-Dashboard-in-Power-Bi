# Sales Performance Dashboard – Power BI

## Project Overview

The **Sales Performance Dashboard** is an interactive Power BI project designed to analyze sales performance, explore product trends, and gain insights into customer behavior. It presents key business metrics through interactive visualizations, making sales data easier to understand and interpret.

## Dashboard Pages

### 1. Overview
Provides a high-level summary of sales performance through key performance indicators (KPIs) and visualizations. It helps users understand overall business performance and identify sales trends.
screenshots/overview.png

### 2. Products
Focuses on product-level performance, helping users explore sales across different products and identify top-performing products.
screenshots/product.png

### 3. Customers
Provides insights into customer-related sales data, supporting the analysis of customer contributions and purchasing patterns.
screenshots/customer.png

## Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and business metrics

## Key Features

- Interactive dashboard pages
- KPI-based sales performance monitoring
- Product performance analysis
- Customer sales insights
- Interactive filtering and data exploration

## Project Goal

The goal of this project is to transform raw sales data into meaningful visual insights that support business performance monitoring and data-driven decision-making.

## How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Explore the Overview, Products, and Customers pages.
4. Use available filters and interactive visuals to analyze the data.
